# Dine Dock POS releases

Windows installers for **Dine Dock POS**, published from the private app repo.

Installed apps (1.0.5 and later) check this repo for updates automatically; cashiers can also use **Help -> Check for Updates**.

Download the latest `Dine-Dock-<version>-setup.exe` from [Releases](../../releases/latest).

Only release assets live here: no source code. Do not delete `latest.yml` from a release; the updater reads it.
